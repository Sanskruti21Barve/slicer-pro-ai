# 🚀 Slicer Pro: Email Intelligence & Game Suite

**Slicer Pro** is a modern, full-stack application that combines an advanced **Email Slicer** utility with an interactive **Domain Memory** game. Designed with a sleek glassmorphic UI, it provides a seamless experience for processing email data.

---

## ✨ Key Features

*   **📧 Email Slicer**: Instantly split email addresses into usernames and domains.
*   **📊 Smart Categorization**: Identifies domains as Commercial, Educational, or Governmental.
*   **📂 Bulk Upload**: Process large .txt lists of emails automatically.
*   **🎮 Domain Memory Game**: A fast-paced matching challenge with custom domain icons.
*   **🎉 Interactive Celebrations**: High-intensity confetti and colorful balloon bursts!
*   **🌙 Dark Mode**: Fully optimized for comfort during late-night sessions.

---

## 🛠️ Quick Installation & Setup

To set up the project instantly, copy and paste the following block into your terminal:

**Step 1: Backend setup:**

1. Clone the Repository
```bash
Open terminal (or Command Prompt) and type:
git clone https://github.com/Sanskruti21Barve/slicer-pro-ai
cd slicer-pro-ai
```
2. Go to the backend folder:
```bash
cd backend
```
3.  Install the Flask web server:
```bash
pip install flask
```
4. Start the backend server:
```bash
python app.py
```
5. Keep this terminal window open so the backend stays running.
 then
```bash
cd ..
```
**Step 2: Frontend Setup (React)**
Now, open a new, second terminal window, go to the project folder, and run these:

1.  Go to the frontend folder:
```bash
    cd frontend
 ```
2.  Install all project dependencies:
```bash
    npm install
```
3.  Launch the interactive UI:
```bash
    npm start
```


## 📂 Project Structure

**frontend**: The React.js application, including CSS glassmorphism styles and celebration logic.

**backend**: Python logic for email processing and categorization.

**node_modules**: (Local only) Folder containing your project dependencies.

## 🚀 How to Use
**Slicing**: Type an email or upload a .txt file in the Dashboard.

**Gaming**: Go to the Domain Memory tab and match all pairs to see the balloon burst!

**Exporting**: Download your results as a CSV from the History tab.
